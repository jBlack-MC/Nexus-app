Current deployment position

No hosting platform is configured. The repository contains no provider-specific configuration: no cloud manifests, infrastructure-as-code or deploy workflow. The README states that public deployment "still needs a hosted API URL" and that the earlier production hostname "was not a configured service" {{F}}. Sections 3 and 4 document what the repository supports, and section 5 contains recommendations only.

Prerequisites

  • API: Node.js 20 (CI) or 22 (Docker image); npm. For containers: Docker with Compose v2.
  • App: Android Studio with SDK Platform 37; JDK 17+ (the build uses a 17 toolchain); an emulator or device on API 24+.
  • A strong JWT_SECRET of 32+ characters, stored outside git (.env* files are git-ignored).

Run the API locally (DEP-01)

# PowerShell, from backend/
npm.cmd ci
$env:JWT_SECRET = node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
npm.cmd start          # listens on http://localhost:5263
curl.exe http://localhost:5263/health
  • Data is written to backend/nexus-data.json unless DATABASE_PATH is set. The file is git-ignored.
  • Keep the same secret across restarts, or every session becomes invalid ([[RB-06]]).
  • Optional test accounts: run docs/seed_test_users.ps1 against a local API only ([[AUD-14]]).

The URL must end in / and match https?://host[:port]/path/, or the Gradle build fails at configuration time ([[TR-07]]).

Run the API in a container (DEP-02)

# from backend/, with JWT_SECRET exported in the shell or a git-ignored .env file
docker compose up --build -d
docker compose ps          # STATUS should become "healthy"
curl http://localhost:5263/health
  • The image is node:22-alpine. It installs production dependencies only, runs as the non-root node user, exposes 5263, and stores data at /data/nexus-data.json on the nexus-data named volume.
  • A Docker HEALTHCHECK calls /health every 30 s. restart: unless-stopped is set.
  • Compose refuses to start if JWT_SECRET is unset (${JWT_SECRET:?…}).
  • Run one replica only ([[CON-01]]). Back up the volume ([[RB-04]]).

Building a release that uses the hosted API

  1. Confirm https://<host>/health responds.
  2. Locally: .\gradlew.bat :app:assembleRelease -PNEXUS_API_URL=https://<host>/api/; or set the GitHub repository variable NEXUS_API_URL so CI builds the release APK and AAB ([[CI-01]]).
  3. Sign the artifacts. Signing is not configured in the repository ([[AUD-08]]).
  4. Complete the release checklist ([[REL-CHECK]]).

Rollback

No versioned deployments exist, so rollback is manual {{F}}. {{R}} Tag each deployed commit. To roll back, redeploy the previous tag against the same data volume. Data written by a newer version stays in the file (the JSON store has no schema version), so take a backup before every deploy.
