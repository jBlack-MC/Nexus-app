System context

Nexus has two deployable parts: the Android app (app/, package com.example.nexus) and the Nexus API (backend/server.js). The app talks only to the Nexus API over REST/JSON. A Retrofit client for the public MyMemory translation API is defined, but nothing in the app calls it ({{F}}, [[AUD-09]]).

Architecture requirements

Technical requirements
IDRequirementHow it is met
TR-01Single-activity MVVM with feature packages.MainActivity hosts NexusNavHost. UI is grouped under ui/<feature>; ViewModels expose StateFlow UI state {{F}}.
TR-02Repositories own all data access; ViewModels never call Retrofit directly.Six repositories are created once in NexusApp (manual DI container). ViewModels take constructor parameters with defaults so tests can inject fakes {{F}}.
TR-03Business rules live outside the UI.domain/HabitScoring is pure Kotlin and is unit-tested {{F}}.
TR-04Local writes are transactional with their outbox record.SyncManager.save() runs the entity write and the PendingChange insert inside withTransaction, under a coroutine Mutex {{F}}.
TR-05Reads never overwrite unsent local edits.SyncManager.read() flushes the queue first and falls back to Room if the flush fails or the network is unavailable {{F}}.
TR-06Room schema changes ship with migrations; no destructive fallback.Migrations 3→4 and 4→5 are registered; fallbackToDestructiveMigration is deliberately absent {{F}}. Schema export is off ([[AUD-12]]).
TR-07API base URL is configured at build time.NEXUS_API_URL Gradle property or environment variable must match https?://host[:port]/path/. It defaults to http://10.0.2.2:5263/api/, and release builds fail unless it starts with https:// {{F}}.
TR-08API validates every write before it touches the store.Zod schemas for register, login, profile (strict), password, project, task, habit and sync. Failures return 400 VALIDATION_ERROR {{F}}.
TR-09API errors use one response shape.Central handler returns { error: { message, requestId, code? } }; in production a 500 message is replaced with "Internal Server Error" {{F}}.
TR-10Idempotent offline replay.POST /api/sync takes operationId (UUID) and stores receipts per user. A repeated operation returns 204 without effect {{F}}.

Interfaces

Nexus API endpoints

All paths are under /api except the root /health. "Auth" means a Authorization: Bearer <JWT> header is required; a missing or invalid token gives 401 UNAUTHORIZED, and a token for a deleted user gives 401 SESSION_EXPIRED.

When NODE_ENV=test only, GET /api/test/error-500 also exists for error-handler tests {{F}}. The app uses the direct project, task and habit endpoints only when no SyncManager is wired in. In the production wiring (NexusApp), writes go through POST /sync {{F}}.

Device integrations

  • Permissions: INTERNET and ACCESS_NETWORK_STATE only {{F}}.
  • ConnectivityManager network callback triggers sync when a network becomes available {{F}}.
  • Android share sheet for CSV export (Intent.ACTION_SEND, text/csv) {{F}}.
  • Backup: allowBackup="true"; shared preferences are excluded from cloud backup and device transfer, but the Room database is not excluded ([[AUD-05]]).
