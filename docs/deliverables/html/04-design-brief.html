2Navigation model

  • Bottom NavigationBar with four destinations: Today, Projects, Habits, Settings. Navigating between them saves and restores state and uses launchSingleTop Implemented.
  • Second-level screens (Project detail, Tasks, Task detail, Profile) use a top app bar with a Back arrow ("Back" content description) Implemented.
  • Create and edit actions use modal dialogs (project, task editor, habit, password), not separate screens Implemented.
  • Destructive actions confirm first: log out and delete account. Deleting a project, task or habit from a list has no confirmation dialog Implemented (Recommendation add an undo snackbar; see IMP-12).

3.2Shape, spacing and type

  • Shapes: small 12 dp, medium 20 dp, large 28 dp rounded corners Implemented.
  • Spacing scale in Spacing.kt: 2, 4, 6, 8, 10, 12, 16, 20, 22, 24, 32 dp. Top-bar logo 32 dp; auth logo 80 dp Implemented.
  • Typography: the system sans-serif for every Material 3 style; body large 16 sp, body medium 14 sp Implemented. No custom font is bundled.
  • Components: NexusPrimaryButton, NexusSecondaryButton, NexusDestructiveIconButton, StatCard, Skeleton, FeedbackState (empty/error with Retry), NexusLogo Implemented.

3.3Motion

Motion.kt fixes durations: screen enter 220 ms, exit 180 ms, list item 220 ms, fade 150 ms, completion bounce 90 + 140 ms, success check 260 ms. Screen transitions slide a quarter width and fade Implemented.

5Responsive behaviour

Layouts are single-column phone layouts built with fillMaxWidth, LazyColumn and horizontally scrolling chip rows. Window insets are handled with statusBarsPadding. No window size classes or tablet layouts exist; tablet layouts are listed as planned Implemented. Landscape behaviour has not been tested Unknown.
